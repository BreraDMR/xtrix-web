# Xtrix Frontend

React + TypeScript frontend for Xtrix.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Testing

```bash
npm test
```

## Configuration

The API base URL is configured in `vite.config.ts` proxy settings.
